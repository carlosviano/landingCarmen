# Estimada Carmela – claude.ai artifacts backup

Exported 2026-11-25 before leaving the work claude.ai account. Design artifacts need the claude.ai Design tool to render; the .dc.html files and canvas.json are the source; images are in assets/ (see MAP.md). Web pages open directly in a browser.

Notes:
- Design folders hold `index.html` (the Design tool's loader shell, identical in every folder), `project/*.dc.html` (one file per board) and `project/canvas.json` (board layout and canvas notes). The Design tool's runtime (`artifact-type/`, `SKILL.md`) was not exported.
- No Design artifact had documents in its `pieces` database, so there are no `db-pieces.json` files.
- Web pages have no asset store. "Ficha anotada" is the only one with extra published files; its working copy (page + images side by side) is in `ficha-anotada-de-estimada-carmela/`.
- "Ficha de tarta en una pantalla", "Eventos Estimada Carmela" and "Carta Estimada Carmela" are older canvas pages: the whole editor and design live inside the single HTML file.
